- **Pools [W1-07]**: Skip the atomic pool Get/Put counter updates while metrics are disabled, so the default (metrics off) path pays one predictable branch instead of two locked read-modify-write operations per pool operation. Allocations and bytes per operation are unchanged. Microbenchmark results are CPU-dependent (large gain on Intel Xeon, small gain on AMD Zen4, small loss on AMD Zen3 for `PoolGetPut/serial`); see the pull request for the amd64 gate numbers.
