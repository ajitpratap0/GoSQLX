- **Transpiler**: `Transpile` skips operator retargeting when the source cannot contain a retargetable construct; it runs `ast.RetargetOperators` only when the source contains `^ | & # ~ @ ? ! { $`, `<<`, `>>` or `->` (plus the conservative pairs `<-`, `=>`, `:=`; `U&` is caught by `&`). These are detected in the same single byte pass as the existing prefilters. Plain comparisons, arithmetic, joins and DML skip the reflective walk. Output and error text are unchanged, enforced by `TestPrefilterEquivalence`, `TestTranspileDifferential` and new per-construct and skip-invariant tests. No API change. amd64 CI matrix A/B (5 randomized layouts per arm): `BenchmarkTranspileRW` cross pairs about −14% to −18%, small cross-dialect shapes about −28% to −35%. [W7-01]
